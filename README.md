# Vortex

A Vulkan-based game engine written in C#.

## Requirements

- [.NET SDK](https://dotnet.microsoft.com/download) 10.0.100+.
- GPU and driver with Vulkan 1.4 support.
- Linux or Windows.

## Building and running

```sh
dotnet build
dotnet run --project VortexEditor
```

Run from the repository root.
